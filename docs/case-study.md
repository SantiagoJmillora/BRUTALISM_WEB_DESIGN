# Case study — OPUS Brutalist Web Redesign

> Fed at the end of each phase: problem, process, discarded options, result, Lighthouse metrics, learnings, and the experience of working with the Fable model.

## 1. Problem

**Santiago's audit (2026-11-12):** OPUS has outstanding structures that could be exploited visually, but the current website doesn't transmit the "magic" that brutalist architecture has when combined with landscape. Design mandate derived from this: oversized typography that passes **in front of and behind** the structures (type/photo interleaving).

**Complementary findings (site inventory, 2026-11-12):**

- **The work outshines the website.** WAF/BLAP/CEMEX-winning projects are presented as uniform Squarespace thumbnail grids — no hierarchy, every project weighs the same, nothing "screams".
- **No conversion path.** There is no clear call to action anywhere: contact is a page with an address, phone, WhatsApp and a newsletter block. No way to book a conversation about a project.
- **Visible neglect:** the newsletter block shows a raw Squarespace admin placeholder ("Este formulario de suscripción… necesita una opción de almacenamiento") on every page; page titles carry leftover prefixes ("EST- premios · awards"); a collaborator's name is missing its first letter.
- **Long single-column pages** with repeated newsletter/footer blocks; image-heavy grids with "Ver tamaño completo" links to raw JPGs.
- **Credibility exists but is buried:** ~60 projects and a 2006–2025 award history (including the BLAP Gran Premio and a WAF category win) live in plain text lists far from any decision point.

Opportunity: radical hierarchy + one dominant CTA ("Book a consultation") + awards as social proof at the decision points.
